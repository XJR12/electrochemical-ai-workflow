# LSV 分析 + 绘图（新版，试用中）

本目录是 2026-08-04 开始的新一版 LSV 模块，验证通过后再决定并入或淘汰 电化学数据处理/ 下的旧版 lsv_analysis.py。

## 文件

- lsv_analysis.py：解析 txt，自动识别 η10/η100，按 直接测/iR补偿 分组选最优曲线，输出中文 CSV（UTF-8 BOM）。选线：η10 差距不超过 5 mV 的候选里优先选 η100 最低；差距大则标记“手动”并用 --pick 指定。
- lsv_plot.py：自动画图。每个样品组：直接测曲线一张图，iR补偿曲线一张图。
- config.yaml：绘图样式配置（dpi、字体、线宽、坐标标签、x 轴刻度）。
- data/：放原始 txt。
- output/：分析 CSV 与图片。

## 用法

```powershell
python lsv_analysis.py --input-dir "数据目录" --output-dir "输出目录"
python lsv_plot.py --input-dir "数据目录" --output-dir "图片目录" --config config.yaml
```

脚本内部会把路径转成绝对路径，从任意目录运行都可以；配置和默认输出目录相对脚本自身定位。

## 绘图规则

- x 轴起点固定 1.4 V；终点取该图所有曲线最大电位中的最小值，四舍五入到 0.01 V。
- x 大分度 0.05 V（0.05 结尾也有数字），小分度 0.025 V 且不标数字。
- 两个坐标轴标题加粗。
- y 轴 0 到该 x 范围内最高电流，少量留白。
- 图片无标题，用文件名区分：直接测 = 目录名（空格转 -），iR = 目录名 + -iR。
- 图例：直接测 = 目录名-1/-2/-3；iR = 目录名-iR-1/-2/-3。

## 对比图

- lsv_compare.py：自动生成对比图，输出到 output/对比图/。
- 总图：LSV.png（所有条件直接测最好曲线）、IR.png（所有条件 iR 最好曲线）。
- 自动分组：按目录名空格拆词，取至少 2 个目录共有的条件词生成 对比-<词>.png / 对比-<词>-iR.png；贯穿所有目录的恒定词（如都是 3%）自动跳过。
- 选线：η10 差距 ≤ gap_mv 视为并列，其中选 η100 最低；差距更大则列出候选并在 选择说明.txt 标记，可用 --pick "目录=文件名" 指定。
- 极差样品：η10 比组内中位数高 exclude_mv 以上自动剔除，不画入对比图。
- y 轴：多数曲线达到 100 时 0-100，否则 0-10；x 轴 1.4 V 起，终点按达到 100 的曲线自动收。
- 需要特殊跨词分组时，可在 config.yaml 的 compare.manual_groups 里手动写组。
