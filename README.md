# 科研 AI 助手

个人科研工作流助手：把重复、机械的工作交给 AI 和脚本，把实验设计、结果判断、科学思考留给自己。

## 目录布局

| 文件夹 | 用途 | 状态 |
| --- | --- | --- |
| 电化学数据处理/ | LSV/CV/EIS 解析、计算、出图 | 占位 |
| 文献知识库/ | 检索、结构化抽取、材料对比 | 占位 |
| 图像分析/ | SEM 粒径统计、形貌辅助判断 | 占位（暂缓） |
| 报告生成/ | 参数汇总、追溯清单、报告 | 占位 |
| 项目模板/ | 标准实验目录模板 | 占位 |
| 文档/ | 架构、安全规范、工具评估 | 占位 |
| 临时文件/ | 中间产物与临时文件，可随时清空 | 使用中 |
| 长期记忆/ | 个人与项目长期背景文档（自我介绍、工作流构想等） | 使用中 |
| 工具发现与评估/ | 先找成熟工具，再决定是否自研 | 占位 |

## 具体项目

具体科研项目以顶层文件夹存放（例如 RuO2析氧项目/），与通用工具模块分离；工具通过参数读取项目路径，数据不混入工具代码。

## 核心原则

- 原始数据只读，AI 不修改、不生成实验数据
- 固定任务交给固定脚本，变化任务交给 AI/Skill
- 所有结果可追溯：论文图 → 处理数据 → 脚本 → 原始数据
- 人工确认是最终环节

## 路径约定

- 所有脚本使用相对路径（相对项目根目录或运行时指定目录），不硬编码绝对路径
- 顶层文件夹可随时手动新增、改名、合并，脚本通过参数或扫描发现，不依赖固定清单
- 中间产物统一放 临时文件/，不要把原始数据或最终结果放在那里
