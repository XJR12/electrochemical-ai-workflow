# 科研 AI 自动化工作流总结（收藏版）

## 1. AI Agent / Skill 和普通脚本的区别

核心区别：**任务是否固定。**

如果任务完全固定：

> AI帮你写一次 Python 脚本 → 以后直接运行

反而是最可靠的方法。

例如 LSV：

```
LSV数据(txt/csv)
↓
固定脚本
↓
计算η10/Tafel
↓
生成论文级图片
```

这种情况下，不需要Agent。

------

如果任务经常变化：

例如：

- 不同仪器数据格式不同
- 导师临时要求增加分析
- 图风格改变
- 数据处理流程调整

那么 Agent/Skill 更有优势。

它可以：

- 理解需求
- 修改已有脚本
- 调用不同工具
- 管理多个流程

------

# 2. Skill 本质是什么？

Skill不是“替代代码”。

它更像：

> AI调用工具的工作规范 + 方法库 + SOP。

例如：

```
Electrochemistry Skill

规则：
- 原始数据不可修改
- 默认处理LSV/CV/EIS
- 使用固定绘图模板
- 输出600 dpi图片
- 保存计算过程

工具：
- LSV_analysis.py
- Tafel.py
- EIS_fit.py
```

AI负责调度，代码负责执行。

------

# 3. 科研中最安全的AI使用方式

不要：

```
实验数据
↓
AI
↓
论文结果
```

危险。

应该：

```
Raw Data（原始数据，只读）
↓
分析程序
↓
Processed Data
↓
Figure
↓
人工确认
```

原则：

> AI可以分析数据，但不能修改或创造实验数据。

------

# 4. 如何避免AI造成学术不端？

核心：

不要相信AI，而是限制AI。

规则：

1. Raw_Data文件夹只读
2. AI只能读取原始数据
3. 输出必须保存到新文件夹
4. 保留分析脚本
5. 保留计算日志

例如：

```
RuO2_Project

├── Raw_Data
│   └── LSV001.txt（不可修改）

├── Analysis
│   └── process_LSV.py

├── Result
│   └── LSV001_processed.csv

└── Figure
    └── LSV001.png
```

任何结果都能追溯：

论文图 → 处理数据 → 脚本 → 原始实验数据

------

# 5. AI会不会修改数据？

不会“故意造假”，但可能误解任务。

危险：

“帮我优化LSV曲线”

AI可能：

- 平滑
- 去异常点
- 改baseline

安全：

“使用原始数据计算η10，不修改任何数据，只生成图片。”

------

# 6. Origin自动画图的问题

目前AI通常不会：

```
打开Origin
↓
点击按钮
↓
套模板
↓
导出图片
```

因为Origin不是开放生态。

更推荐：

方案1（推荐）：

Python复刻Origin模板：

```
CSV
↓
Python matplotlib
↓
600dpi论文图片
```

优点：

- 自动化
- 可重复
- 不依赖Origin

方案2：

Python调用Origin COM接口。

可以做到自动操作Origin，但：

- 配置麻烦
- 稳定性一般

------

# 7. 对你的电化学科研，最佳路线

不要一开始追求“AI实验室”。

推荐：

阶段1：

AI帮你写固定工具：

例如：

- LSV自动处理
- Tafel计算
- EIS拟合
- 数据整理
- 自动画图

阶段2：

把多个工具组合成Skill：

```
Electrochemistry Skill
```

让AI知道：

- 数据在哪里
- 用什么方法
- 输出什么格式

阶段3：

Agent自动管理流程：

```
导入新数据
↓
识别类型
↓
调用对应工具
↓
生成结果
↓
生成报告
```

------

# 8. 最终理解

未来科研AI不是：

“AI替你做实验。”

而是：

```
AI = 助理/调度员
代码 = 工具
实验数据 = 核心资产
人 = 最终判断者
```

最可靠的模式：

> 把确定性的工作交给代码，把变化性的判断交给AI。

对于你的RuO₂、电化学测试流程，最适合的是：
**固定脚本 + AI维护 + 后期Agent整合。**

不要让AI直接碰原始数据，让AI帮你减少重复劳动，把时间留给实验设计和机理分析。
