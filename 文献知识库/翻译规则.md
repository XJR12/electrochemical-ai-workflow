# 电化学论文翻译规则

## 目的

给需要精读的电化学论文做中文化翻译，重点保证科学信息不丢失，不追求“漂亮中文”。

## 优先级

科学准确性 > 信息完整性 > 专业术语一致性 > 中文流畅性。

## 流程

1. 用 pdfplumber / pypdf 提取 PDF 正文
2. 校正文本：恢复上下标、化学式、单位（如 RuO2 → RuO₂、cm 2 → cm⁻²）
3. 按本规则翻译，逐段输出【原文】【翻译】【备注】
4. 翻译完自动做一次“审稿人检查”，写进文末审稿记录
5. 输出译文
6. 把源 PDF 复制到输出文件夹，与译文放在一起，方便对照阅读

## 术语处理

- OER、HER、RHE、ECSA、TOF、η、ΔG 等不强行中文化，保留原样。
- 首次出现可写“中文（英文全称, 缩写）”，之后统一用缩写。
- 化学式与样品名保持原样：RuO₂、RuMnOx、Ce-doped RuO₂ 不翻译。
- OER 不翻译。

## 输出格式

每段：

```text
【原文】
...

【翻译】
...

【备注】
...
```

长论文按章节：Abstract / Introduction / Experimental / Results and Discussion / Conclusion。

## 图表处理

- 不识别图表，保留 Figure/Table 引用。
- 正文依赖图片但无法判断趋势时，标 `[需要查看 Figure x 确认]`。

## 审稿清单

- 化学式与元素是否错误
- 电位、RHE、电流密度、单位是否丢失
- 语气是否被改变（may/suggest 不能升级成确定结论）
- 是否有信息遗漏或自行补充
