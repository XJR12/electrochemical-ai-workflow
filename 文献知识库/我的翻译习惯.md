# 我的翻译习惯

本文件记录已确认的翻译偏好，AI 维护，用户可随时手工修改。

## 已确认

- OER 不翻译，保留原样。
- 输出格式：每段【原文】【翻译】【备注】。
- 每次翻译后自动做二次审稿，结果写在译文文末。
- 不识别图表，只保留 Figure/Table 引用；依赖图片无法判断时标 `[需要查看 Figure x 确认]`。
- 译文先放 临时文件/论文翻译/，确认后再归档。
- 质量活性单位用 mg<sub>Ru</sub>⁻¹（下标 Ru + 上标 -1）。
